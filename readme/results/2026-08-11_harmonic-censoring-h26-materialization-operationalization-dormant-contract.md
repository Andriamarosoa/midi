# H26 — contrat dormant d'opérationnalisation de la matérialisation

Statut : `PENDING_BATCH_EXTERNAL_REVIEW`. Le contrat relie les validateurs de
preuve et d'autorité existants au materializer existant, sans les réécrire.
Seule l'intégration avec doubles est autorisée; aucune preuve, autorité,
destination, population ou matérialisation réelle ne peut être créée.
