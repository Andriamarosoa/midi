Discussion : Harmoniques, détection des fondamentales et gestion des datasets

Q : Annoter les harmoniques d’une attaque de note est-il risqué ? R : -
Oui, si les harmoniques sont annotées comme des notes réellement
jouées. - Il vaut mieux annoter la note fondamentale comme vérité
terrain et utiliser les harmoniques comme information auxiliaire.

Q : Deux notes superposées peuvent-elles créer une autre note ? R : -
Elles ne créent généralement pas une nouvelle fondamentale physique. -
En revanche, elles peuvent produire une fondamentale virtuelle, des
battements ou des produits d’intermodulation dans un système non
linéaire.

Q : Connaît-on les harmoniques d’une fondamentale ? R : - Les fréquences
théoriques sont connues (f0, 2f0, 3f0, …). - En revanche, leurs
amplitudes et leur évolution temporelle varient.

Q : Peut-on reconnaître les harmoniques en analysant tout le son ? R : -
Oui. L’analyse de toute l’attaque, du sustain et de la décroissance
permet d’identifier beaucoup plus facilement quelles composantes
appartiennent à une même note.

Q : Et en polyphonie ? R : - C’est plus difficile car plusieurs séries
harmoniques se chevauchent. - Les contraintes physiques de la guitare
peuvent aider à résoudre les ambiguïtés.

Q : Connaît-on l’arrangement des harmoniques ? R : - Les positions
théoriques sont connues. - La répartition réelle de l’énergie ne l’est
pas.

Q : Une meilleure labellisation des superpositions aide-t-elle ? R : -
Oui, si les labels décrivent correctement la réalité physique et
n’inventent pas de nouvelles notes.

Q : Existe-t-il une méthode pour détecter les fondamentales ? R : - Oui
: YIN, pYIN, autocorrélation, HPS, cepstre, modèles harmoniques, NMF,
réseaux CNN/TCN/Transformers, etc.

Q : J’ai les notes mais pas les harmoniques. R : - Les harmoniques sont
déjà présentes dans l’audio. - Elles peuvent être estimées
automatiquement à partir des annotations de notes.

Q : Existe-t-il un dataset avec les harmoniques annotées ? R : - Aucun
dataset public connu ne fournit une annotation complète des partiels. -
GuitarSet est le meilleur candidat pour générer automatiquement ces
annotations, grâce à ses six canaux séparés (un par corde).

Q : La durée des harmoniques est-elle importante ? R : - Oui. Il est
préférable d’enregistrer leur évolution temporelle (trajectoires
d’amplitude et de fréquence) plutôt qu’une seule valeur fixe.

Q : Toutes les harmoniques sortent-elles ? R : - Non. Certaines sont
très fortes, d’autres faibles ou non observables. - Les hautes
harmoniques disparaissent souvent rapidement.

Q : E3 est-il un harmonique de E2 ? R : - Oui. E3 correspond à la
deuxième harmonique (H2) de E2.

Q : À quel moment la fondamentale devient-elle détectable ? R : - Les
premières estimations peuvent apparaître après quelques millisecondes,
mais une détection robuste dépend de la fréquence. - Pour les graves
(E2), environ 30 à 50 ms sont souvent nécessaires.

Q : Peut-on pousser 36 Go sur Git ? R : - Pas dans un dépôt GitHub
classique. - Recommandation : * Git pour le code. * Git LFS si
nécessaire. * DVC, Hugging Face, S3, Backblaze ou autre stockage distant
pour les données.
