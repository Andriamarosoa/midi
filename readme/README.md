## Format obligatoire

Chaque nouveau compte rendu doit indiquer :

- la date et la branche Git ;
- les données et le split utilisés ;
- les paramètres ou le changement testé ;
- les métriques obtenues ;
- les limites, régressions et anomalies ;
- les chemins des rapports ou artefacts de preuve.

Les modes d’emploi appartiennent aux commandes `--help`, aux scripts ou aux
commentaires du code, pas à ce dossier.
